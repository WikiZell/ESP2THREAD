# Building

The initial toolchain is ESP-IDF v5.5.4. Exact setup and build commands will be
added with the first compiling firmware milestone. This placeholder is kept
explicit so the repository does not claim that an untested command works.

Expected prerequisites:

- Git with submodule support
- ESP-IDF v5.5.4 and its installed Python environment
- Seeed Studio XIAO ESP32-C6 connected through native USB

No Wi-Fi password or Thread dataset belongs in `sdkconfig`, a command line,
source code or a committed file.
